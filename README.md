# Xin Huang — Personal Website

A static personal website with a CV, research statement, photograph, and transcript links.

## Publish with GitHub Pages

1. Create a public repository named exactly `carriehxx.github.io` under the `carriehxx` account. If that repository already exists, review its contents before replacing anything.
2. Upload the contents of this folder to the repository root. `index.html` must be at the top level, alongside `styles.css`, `favicon.svg`, `.nojekyll`, and `files/`.
3. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. GitHub Pages will display the website address when publication finishes.

## Update the website

Edit `index.html` for text and links, `styles.css` for layout, and the files under `files/` for downloadable documents and the photograph. Commit the changes to `main`; GitHub Pages will publish the new version automatically.

The transcript PDFs are included as supplied and were not parsed or reviewed.
